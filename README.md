## Shipped

### 🚢 [Shipworthy](https://github.com/chattyyee/shipworthy)
![last commit](https://img.shields.io/github/last-commit/chattyyee/shipworthy) ![top language](https://img.shields.io/github/languages/top/chattyyee/shipworthy)

Decides whether an ambiguous product requirement is ready to build, and shows the evidence behind the decision.

Models propose findings; a deterministic policy computes the readiness state, and every finding has to cite retrieved evidence by ID and exact quote — no model can talk the system into READY. Built alongside the Claude Certified Architect curriculum.
